[[1. Introduction|上一讲]]提出了一个问题：**生命怎样用一组共同的分子，构建出复杂的细胞？** 这一讲开始解释其中的化学基础。

整节课可以串成一条因果链：
**原子怎样成键 → 分子具有哪些性质 → 分子怎样相互作用 → 脂质为什么能在水中形成细胞膜。**

## 1. 先建立尺度感：从化学键到细胞膜

生物学中的许多现象发生在肉眼看不到的尺度上。理解大小关系，有助于把后面学到的结构放进正确的位置。

| 单位    | 与米的关系   | 常见用途          |
| ----- | ------- | ------------- |
| 皮米，pm | 10⁻¹² m | 原子尺度的距离       |
| 埃，Å   | 10⁻¹⁰ m | 化学键长度、原子间距离   |
| 纳米，nm | 10⁻⁹ m  | 蛋白质、DNA、细胞膜厚度 |
| 微米，μm | 10⁻⁶ m  | 细胞大小          |

记住：
**1 nm = 10 Å；1 μm = 1,000 nm。**
补充几个参照：
- 一根典型 C—C 单键约长 **1.5 Å**。
- DNA 双螺旋直径约 **2 nm**。
- 脂质双层厚度通常约 **4–5 nm**。
- 许多真核细胞直径约 **10–100 μm**。

这意味着：细胞膜虽然能包围整个细胞，本身却只是薄薄的分子层。

## 2. 共价键构建分子，非共价作用组织分子
这是本节课最重要的区别。

### 共价键：哪些原子连在一起？
共价键通过原子间**共享电子对**形成，构成分子的基本骨架。
例如：
- 蛋白质中，氨基酸通过共价的肽键连接。
- DNA 中，一条链上的核苷酸通过共价的磷酸二酯键连接。
- 一个磷脂分子内部，头部和尾部也通过共价键连接。

改变这些连接，往往意味着发生了化学反应。

### 非共价作用：分子怎样排列和结合？
非共价作用参与：
- 蛋白质折叠成特定形状；
- DNA 两条链配对；
- 酶识别并结合底物；
- 磷脂聚集成脂质双层。

它们也可以发生在**同一个分子的不同部位之间**。例如，一个蛋白质内部相距较远的两段，可以形成氢键。

以 DNA 为例：

| 观察对象            | 主要连接方式        |
| --------------- | ------------- |
| 一条 DNA 链的糖—磷酸骨架 | 共价键           |
| 两条链之间的碱基配对      | 氢键            |
| 相邻碱基的堆叠         | 包含范德华作用等非共价作用 |

因此，DNA 解链时，不需要把每条链的共价骨架切断。
**生命需要结构足够稳定，又需要结构能够变化。共价骨架与大量可重组的非共价作用，共同满足了这两个要求。**

### 为什么教授一直强调水？
因为细胞中的相互作用大多发生在水里。
两个基团结合以前，可能已经在与水相互作用。它们结合时，既获得了彼此之间的新作用，也可能失去原先与水之间的作用。
所以不能只问：
> “这两个基团能不能形成氢键？”

还要问：
> “它们结合后，与原来各自接触水相比，整个系统是否更有利？”

这是理解蛋白质折叠和膜形成的关键。
讲稿中的“75% 水”和各类分子的比例，应理解为帮助建立概念的示意；不同细胞、组织和人体状态的组成差别很大，并非统一常数。

## 3. 读懂分子结构：常见元素怎样成键
生命分子的主要元素是：
**C、H、N、O、P、S，即碳、氢、氮、氧、磷、硫。**
对于常见、中性的生物有机结构，可以先掌握以下规律：

| 元素  | 常见成键情况 | 常见孤对电子 |
| --- | ------ | ------ |
| H   | 1 根单键  | 无      |
| C   | 总键级为 4 | 通常无    |
| N   | 3 根键   | 1 对    |
| O   | 2 根键   | 2 对    |

“总键级为 4”表示：碳可以形成四根单键，也可以形成一根双键加两根单键。**双键算两份，三键算三份。**

这些是入门时识别常见结构的规则，并不是所有化合物都必须符合的绝对定律。

### 孤对电子为什么重要？

孤对电子是不参与通常成键的价电子对，但它们并非没有作用。
它们可能：
- 接受 $\mathrm{H^+}$，改变基团的电荷；
- 作为氢键受体的一部分；
- 参与化学反应。

例如，一个普通胺基可以接受质子：

$$
\mathrm{R\text{-}\ddot{N}H_2 + H^+ \rightleftharpoons R\text{-}NH_3^+}
$$

式子里 N 上的两点就是那对孤对电子：氮用它和没有电子的 $\mathrm{H^+}$ 形成新的 N—H 键（右边多出来的那根 H）。因此右边的 $\mathrm{R\text{-}NH_3^+}$ 中，氮有四根键，通常不再有可用的孤对电子。

这里的 **R** 表示“分子的其余部分”。

接受 $\mathrm{H^+}$ 后：
- 氮形成四根键；
- 基团带正电；
- 原来可用于接受氢键的孤对电子不再可用。

一个质子的差别，就能改变这个基团喜欢与谁相互作用。

### 带不带电，不能只看有没有氮或氧
讲稿关于“氮在某个 pH 下会质子化”的说法，需要加上条件：
**质子化程度取决于环境 pH，以及这个具体基团的 pKa。**
对于一对酸与共轭碱：
- **pH < pKa**：较多处于质子化形式；
- **pH > pKa**：较多处于去质子化形式；
- **pH = pKa**：两种形式浓度相等。

例如，赖氨酸侧链的 pKa 约为 10.5，在 pH 7 左右通常带正电。但不能因此推断“所有含氮基团在 pH 7 都带正电”。

磷在本课程中主要以**磷酸基团**出现，参与核酸骨架、ATP 和蛋白质磷酸化。硫则常见于巯基等结构；它与氧有相似性，但化学行为并不完全相同。

## 4. 官能团：从结构预测性质
**官能团是分子中具有特征性化学行为的一组原子。**

看到一个陌生分子时，先寻找官能团，通常比背诵整个分子的名字更有用。

| 官能团      | 简式            | 生理条件下常见特点           |
| -------- | ------------- | ------------------- |
| 羟基       | R—OH          | 极性，通常中性，可参与氢键       |
| 羧基／羧酸根   | R—COOH／R—COO⁻ | 普通羧基在接近中性 pH 下通常带负电 |
| 胺基／质子化胺基 | R—NH₂／R—NH₃⁺  | 许多脂肪胺在接近中性 pH 下带正电  |
| 磷酸基团     | 含 P 与 O 的基团   | 常带负电，电荷取决于连接方式和 pH  |
| 巯基       | R—SH          | 可参与反应；去质子化后为 R—S⁻   |

### 用乙醇与长链醇理解“整体性质”
乙醇是 $\ce{CH3-CH2-OH}$：

![乙醇的骨架结构式](attachments/ethanol-skeletal.png)

- CH₃—CH₂ 部分偏非极性；
- —OH 可以与水形成氢键；
- 由于碳链很短，乙醇可以与水混溶。

如果把碳链延长很多，而仍然只有一个 —OH，分子的疏水部分就会越来越突出，水溶性通常下降。

所以：
**有亲水基团，不等于整个分子一定容易溶于水；还要看亲水和疏水部分的相对大小。**

这正是理解脂质的准备。

## 5. 酯、酰胺与磷酸酯：生命材料怎样连接

教授接着介绍几种组合官能团。这些连接方式会在后续课程中不断出现。
### 酰胺：蛋白质的连接基础

形式上，可以把羧酸与胺形成酰胺写成：

$$
\mathrm{R\text{-}COOH + H_2N\text{-}R' \rightarrow R\text{-}C(=O)\text{-}NH\text{-}R' + H_2O}
$$
其中 **—C(=O)—NH—** 是酰胺结构。

蛋白质中连接氨基酸的**肽键，就是一种酰胺键**。

特别要注意：

**胺和酰胺不是同一种官能团。**

酰胺氮的孤对电子与邻近羰基发生共振离域，因此：
- 不像普通胺那样容易接受 H⁺；
- 通常不作为氢键受体；
- 如果氮上有 H，N—H 可以作为氢键供体；
- 邻近羰基氧可以作为氢键受体。

这些性质决定了蛋白质骨架怎样形成氢键网络。

### 酯：常见于储能脂肪和膜脂
形式上：
$$
\mathrm{R\text{-}COOH + HO\text{-}R' \rightarrow R\text{-}C(=O)\text{-}O\text{-}R' + H_2O}
$$
产物中的 **—C(=O)—O—** 是酯结构。

例如：
- 甘油有三个羟基；
- 三个羟基分别与脂肪酸形成酯；
- 得到三酰甘油，也就是通常说的甘油三酯。

### 磷酸酯与磷酸二酯
磷酸基团可以通过氧与有机基团连接，形成磷酸酯。
当一个磷酸基团分别与两个醇来源的氧形成酯连接时，就是**磷酸二酯**。DNA 和 RNA 骨架中的典型连接属于这一类。

| 生物结构 | 需要认识的连接 |
| --- | --- |
| 蛋白质骨架 | 肽键，即酰胺键 |
| 三酰甘油、常见甘油磷脂中的脂肪酸连接 | 酯键 |
| DNA、RNA 骨架 | 磷酸二酯键 |

上述“脱去一分子水”的写法用于理解结构关系。**细胞内实际合成这些键，通常需要活化底物、酶和能量耦联**，并不是把游离原料混进水中就能高效完成。

## 6. 非共价作用为什么能同时带来稳定和动态

讲稿用能量数量级做比较：
- 典型 C—C、C—H 共价键：约 **80–100 kcal/mol**；
- 许多单个非共价相互作用：约 **1–10 kcal/mol**，随环境变化很大。

这里主要是帮助你理解强弱差别。共价键解离能与水中分子结合的自由能不是可以直接等同的量，也不要把所有非共价作用都套进固定范围。

### 单个弱，整体可以很稳定
一个相互作用比较容易被扰动，不表示由数百个相互作用共同维持的结构就很容易瓦解。
例如，蛋白质可以：
- 整体保持折叠；
- 局部短暂移动；
- 接受底物进入；
- 调整形状；
- 释放产物。

动态不要求每次都拆掉整个结构。
这也说明，**“较弱”并不等于“不重要”**。大量弱作用的排列方式，决定了分子识别的准确性。

## 7. 静电作用与氢键：怎样在结构图中识别

### 静电作用：先找正负电荷
例如：
**R—NH₃⁺ ··· ⁻OOC—R′**
正电基团与负电基团之间可以形成吸引，在蛋白质中常称为**盐桥**。

识别顺序：
1. 找出带电基团；
2. 判断在当前 pH 下是否确实带电；
3. 看它们是否足够接近；
4. 考虑水和周围离子的影响。

水会屏蔽电荷间的作用，也会水合这些带电基团。因此，水中两个电荷靠近后的净收益，不仅取决于“正负相吸”。
低极性环境中，已存在的电荷之间吸引可能更强；但把电荷从水中埋进低极性环境，本身也可能付出很大代价。
### 氢键：找供体与受体
常见表示是：
**D—H ··· A**
- **D—H**：氢键供体；
- **A**：氢键受体；
- 实线：原有共价键；
- 点线：氢键。

在本课程的常见生物分子中：
- O—H、N—H 常可作为供体；
- 具有可用孤对电子的 O、某些 N 常可作为受体。

“供体”不表示 H⁺ 已经完全离开原来的原子。**形成氢键与发生完整的质子转移，是不同的事情。**
### 最值得掌握的判断表

| 基团或原子 | 氢键供体？ | 氢键受体？ |
| --- | --- | --- |
| 醇羟基 —OH | 是 | 是 |
| 羰基氧 C=O | 否 | 是 |
| 普通中性胺 —NH₂ | 是 | 是 |
| 质子化胺 —NH₃⁺ | 是 | 否 |
| 酰胺中的 —NH— | 是 | 该氮不是 |
| 羧酸根 —COO⁻ 中的氧 | 否 | 是 |
| 普通烃链的 C—H | 入门分析中通常不算 | 通常不算 |

两种常见错误：
- **“有孤对电子就一定能接受氢键。”** 还要看电子是否可用，酰胺氮就是关键例外。
- **“有氢就能提供氢键。”** 普通烃链上的 C—H，一般不按常规氢键供体处理。

此外，氢键有方向性。供体与受体类型匹配，只意味着有形成的可能；实际还需要合适的距离与角度。

## 8. 疏水效应与范德华作用：为什么油和水分开

### 疏水效应：必须把水纳入解释
烃链富含 C—C 和 C—H，不能像羟基那样有效地参与水的氢键网络。
非极性表面分散在水中，会影响附近水分子的排列和自由度。当这些非极性部分聚集时：
- 暴露给水的总表面积减少；
- 周围部分水分子得到释放；
- 在适当条件下，整个系统的自由能降低。

因此，疏水效应更准确地说是一种**由溶剂参与驱动的聚集倾向**，不是两个疏水基团之间存在一种特殊的共价键。
